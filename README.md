# moondog-cdn

문도그 컨트롤룸 인스타그램 게시용 **공개 이미지 버킷**입니다. (@__moondog)

여기에 올린 파일은 아래 형식의 공개 직접 URL로 접근됩니다:

```
https://raw.githubusercontent.com/stvfcpersonaltraining-dotcom/moondog-cdn/main/<폴더>/<파일명>
```

- `stories/` — 인스타 스토리용
- `posts/` — 단일 피드 이미지
- `carousel/` — 캐러셀용

업로드는 프로젝트 루트의 `moondog-publish.sh` 스크립트를 사용하세요.

> 주의: 이 저장소는 공개입니다. 올린 이미지는 git 기록에 영구 보존됩니다.
